# Security Policy

## Scope

The current tree is a visual portfolio with documentation and PNGs, not a
running service, application distribution, or supported software release.
There are no current runtime dependencies, APIs, or application build jobs
to assess through this publication.

Earlier commits are deliberately retained and still contain source. Removal
from the latest version is not a history purge or a confidentiality guarantee.
See [publication policy](SOURCE-CODE.md).

## Private Reporting

Do not post credentials, personal information, private code, database contents,
or exploit details in public issues, discussions, or pull requests. Contact
the maintainer through an independently agreed private channel before sending
sensitive reproduction material. No response-time or security-certification
commitment is implied by this portfolio.

For vulnerabilities affecting the official FACT website, use its own operator's
reporting process. This showcase does not establish that its maintainer operates
that website or can authorize testing it.

## Accidental Disclosure

If confidential material is newly published, pause further publication and
contact the owner privately. Exposed credentials require revocation or rotation;
deleting a current file alone is not sufficient containment. Any coordinated
history rewrite needs explicit approval because it changes existing commits
and cannot recover copies already obtained by other people.

The current seven-commit update follows the owner's decision to preserve the
earlier history. It is not represented as sensitive-data remediation for that
history or as a security audit of any private implementation.
