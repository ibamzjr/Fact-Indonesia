# Curated Laravel Engineering Samples

> Sanitized engineering samples derived from RoyalVilla. Runtime configuration,
> routes, persistence schema, credentials, and operational integrations are
> intentionally omitted. This directory is not a runnable application.

The examples retain the most useful engineering ideas while removing identity
data, payment details, raw request logging, deployment wiring, and private
business configuration.

## Included

- Typed property, submission, image, and promotion-package models.
- Centralized browsing and seller-submission validation.
- A thin Inertia catalogue controller.
- A transactional moderation service and delegation controller.
- Focused feature-test examples for approval and rejection invariants.

The complete Laravel application remains private.
