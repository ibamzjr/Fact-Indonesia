# Contribution Policy

This repository is published for portfolio evaluation under the terms in
`LICENSE.md`. Public availability does not grant a license to redistribute or
deploy it.

Owner-maintained changes should be scoped, verifiable, and accurately described.
Do not commit secrets, user data, database exports, runtime configuration, or
private application code. Keep FACT reference content separate from inherited
property behavior until a real adaptation is implemented.

Run `npm test`, `npm run build`, `npm run build:fact`, and
`npm run check:publication` before pushing. Follow the
[content contract](docs/product/content-contract.md) when updating official
references. Keep owner image checksums current only when an intentional asset
change is authorized; do not replace original images to satisfy a failing test.
