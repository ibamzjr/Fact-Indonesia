# FACT Adaptation Roadmap

The current publication establishes a shared foundation and a documented
visual direction. The following work remains, rather than being represented
as completed features:

1. Define a FACT service and program schema instead of property records.
2. Connect organization content to the presentation layer.
3. Adapt navigation and informational page terminology.
4. Implement an explicit program discovery contract.
5. Design program detail and contact journeys.
6. Replace inherited property-specific FAQ content.
7. Establish accessible enrollment requirements where applicable.
8. Document privacy boundaries for participant information.
9. Add automated content and interface contract checks.
10. Verify mobile, keyboard, loading, and recovery states.

Each item should produce substantive changes and verification before it is
committed. Follow-up work must use its actual creation date.
